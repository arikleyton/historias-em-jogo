# Histórias em Jogo: Gamificação e Quadrinhos Interativos no Ensino de História 🎮📚

Um projeto de extensão focado em unir narrativas históricas, tecnologia e gamificação para criar uma experiência educativa imersiva. 

## 📖 Sobre o Projeto

"Histórias em Jogo" é uma iniciativa de extensão acadêmica que visa transformar o ensino de História por meio da criação de quadrinhos interativos e minigames. Utilizando a biblioteca **Phaser**, o projeto propõe ilustrar e vivenciar eventos históricos de forma lúdica (como, por exemplo, as narrativas sobre o descobrimento do Brasil), engajando ativamente alunos do ensino médio e superior.

O desenvolvimento da ferramenta abrange as seguintes etapas:
- **Roteirização e Pesquisa Histórica**
- **Design de Artes, UI e Som**
- **Programação (Phaser/JavaScript)**
- **Aplicação e Avaliação Pedagógica**

## 🚀 Tecnologias Utilizadas

- **[Phaser 3](https://phaser.io/):** Framework HTML5 para criação de jogos 2D.
- **JavaScript (ES6+)**
- **HTML5 e CSS3**
